# frame.md — Cultivator Promo

## Concept

Warm ink-desk atmosphere: a quiet desk corner where a pixel cultivator keeps daily wooden-fish practice while coding agents work. Soft, slightly playful — temple wood and paper, not neon cyber.

## Palette

| Token | Hex | Use |
|-------|-----|-----|
| bg | `#17140f` | Scene fill (warm near-black) |
| paper | `#f0e4cc` | Headlines / captions |
| muted | `#a89880` | Secondary labels |
| wood | `#8b5a2b` | Accent lines, terminal chrome |
| gold | `#d4a84b` | Merit pops, CTA underline |
| cinnabar | `#c45c26` | `+50` / urgency ghost text |
| terminal | `#6f8f68` | Fake code lines |
| glow | `rgba(212,168,75,0.18)` | Soft radial wash |

## Typography

- Display / captions: **Noto Sans SC** 700–900 (Chinese readability; embed via Google Fonts link)
- Secondary / product: **Montserrat** 700 (CTA Latin "Clawd")
- Mono accent: **IBM Plex Mono** 400 (terminal / deadline ghosts)

## Layout

- Pet is the hero — large, lower-right or center depending on beat
- One big Chinese caption per scene, bottom-safe or center-lower
- Terminal / deadline only as soft background or left PiP — never compete with pet
- Persistent grain + warm radial glow across scenes

## Motion

- Caption: 0.35–0.5s rise + fade (power3.out)
- Scene cuts: hard cut on knock beats for flip / stages
- Merit numbers: quick scale punch
- Ambient: slow glow breath (finite repeats only)
- No purple glow, no Level-Up fireworks — soft gold flash + cloud scroll for check-in
